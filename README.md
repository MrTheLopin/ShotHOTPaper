# ShotHotPaper
Dossier pour le développement de mon jeux ShotHotPaper

## Prototype jouable (version 0.3)

Le premier prototype navigateur est disponible dans `index.html`.

### Jouer en local
Ouvre simplement `index.html` dans un navigateur récent avec une connexion Internet (Three.js est chargé depuis jsDelivr).

### Publier gratuitement avec GitHub Pages
1. Ouvre **Settings** dans ce dépôt GitHub.
2. Va dans **Pages**.
3. Dans **Build and deployment**, choisis **Deploy from a branch**.
4. Sélectionne la branche `PaperHOTMate` et le dossier `/ (root)), puis **Save**.
5. GitHub affichera l'adresse publique du jeu une fois le déploiement terminé.

Aucun abonnement payant n'est nécessaire pour cette première version. Le jeu utilise Three.js via un CDN gratuit.


### Version 0.3 — sensations de jeu
- Déplacements avec accélération et inertie, collisions avec les caisses et limites de l'arène.
- Saut avec gravité et retour au sol.
- Animation procédurale des bras et des jambes pendant les déplacements.
- Recul de l'arme, flash de bouche et trace lumineuse des tirs.
- Dégâts, réaction au recul des impacts et points de vie des adversaires.
- Barre d'intégrité et chargeur visuel de 12 munitions avec rechargement animé.

Commandes : ZQSD / WASD pour se déplacer, souris pour viser, clic gauche pour tirer, R pour recharger, Espace pour sauter.
